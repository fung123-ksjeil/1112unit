# ATLAS · 잠긴 기지 탈출 작전

중등 사회 ② 11단원 「세계 속의 우리나라」를 바탕으로 만든 실시간 방탈출 게임입니다.

## 교실에서 시험하기

1. 교사 PC에 [Node.js](https://nodejs.org/) 22 이상을 설치합니다. 이 저장소의 **Code → Download ZIP**으로 받은 파일을 풉니다. Git을 사용한다면 `git clone https://github.com/fung123-ksjeil/1112unit.git`으로 내려받아도 됩니다.
2. Windows에서는 압축을 푼 폴더의 **Start-Atlas.cmd**를 더블클릭하고 실행 창을 열어 둡니다. 직접 실행하려면 해당 폴더의 터미널에서 `node server.js`를 입력합니다. 별도 패키지 설치는 필요 없습니다. 교사 PC에서 `http://localhost:3000`을 열고 **교사 · 방 만들기**를 선택합니다.
3. 교사 PC의 교실 네트워크 IPv4 주소를 확인합니다. Windows에서는 `ipconfig`를 실행하고 연결된 Wi-Fi 또는 이더넷의 **IPv4 주소**를 확인합니다. 학생이 교사와 통신할 수 있는 교실 네트워크에서 브라우저로 `http://교사PC의IPv4주소:3000`을 열고, 교사가 알려준 6자리 코드를 입력합니다. 교사 1명과 학생 최대 49명이 접속할 수 있습니다.
4. 학생은 캐릭터를 고르고 **방향키·WASD** 또는 화면을 눌러 이동합니다. 가까운 물건은 **E**로 조사하거나 클릭합니다. 화면 우측의 **작전 패널** 버튼으로 패널을 접고, 미니맵으로 구역과 탐험대의 위치를 확인할 수 있습니다.

## 탈출 작전

- **미션**에서 구역마다 수집한 문서·표식·안내판 수와 다음 목표를 확인합니다. 금고를 열면 내 미션에 초록색 표시등과 체크가 켜지며, **수첩**에는 앞서 조사한 단서가 보관됩니다.
- 해안, 시장, 산악 지대를 걸으며 현장 문서 12개를 찾아 수첩에 기록합니다. 짝이 되는 자물쇠에서 초성·넌센스·방향·지역 추리 퀴즈를 풀면 숫자 표식을 얻습니다.
- 각 구역에서 표식 네 개와 순서 안내판 두 곳의 기록을 모아 금고 암호를 풉니다. 세 금고에서 얻은 표식으로 출발 기지 남쪽의 탈출 게이트 암호를 맞힙니다.
- 함정의 노란 경고 원과 순찰 괴물을 피하세요. 작동 중인 함정이나 괴물에 닿으면 출발 기지에서 부활하고, 해당 학생의 단서·표식·금고 기록이 초기화됩니다. 다른 학생의 진행에는 영향이 없습니다.
- **진행판**은 해당 방의 미션 완료 및 부활 시각을 표시합니다. **채팅**을 활용해 힌트를 나눌 수 있고, 각 학생이 직접 탐험하고 잠금을 해제해야 합니다. 수업 탐험 목표 시간은 20~30분이며, 진행 속도와 재도전 횟수에 따라 달라집니다.

교사 PC에서는 열리는데 학생 기기에서 연결되지 않으면 학교 IT 담당자에게 기기 간 통신과 교사 PC의 TCP 3000 포트가 교실 네트워크에서 허용되는지 확인해 주세요. GitHub Pages는 정적 파일을 제공하므로 실시간 방·채팅을 운영하려면 위 Node.js 서버를 실행해야 합니다.

서버를 재시작하면 방과 진행 기록이 초기화됩니다. 같은 탭에서 새로고침하면 기존 방에 다시 연결합니다. 브라우저 수준의 이탈 제한은 학교 관리형 기기 설정에서 제어할 수 있습니다.
